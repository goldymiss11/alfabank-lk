# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного конвейера для малого и микробизнеса, разработанный для хакатона **Альфа-Хак 2026** (кейс АО «Альфа-Банк»).

Сервис связывает клиентский путь предпринимателя (выбор продукта, расчёт лимитов, подача заявки, подписание договора) и внутреннюю обработку банком (обогащение данных, скоринг, кредитная политика, АРМ андеррайтера) в единый интерактивный интерфейс.

![Демонстрация работы кредитного конвейера](docs/video/demo_preview.gif)

> 📹 **Видео полного прохождения сценария (Fast-track, контр-оффер, субсидии, роли):** [docs/video/demo_walkthrough.mp4](docs/video/demo_walkthrough.mp4)

## Быстрый запуск (рекомендуемый для проверки)

Для запуска требуется только **Docker** и **Docker Compose**:

```bash
docker compose up --build
```

После старта перейдите в браузере:
- **Интерфейс (Кабинет + АРМ банка):** [http://localhost:3000](http://localhost:3000)
- **API бэкенда:** [http://localhost:8000](http://localhost:8000)
- **Health Check:** [http://localhost:8000/health](http://localhost:8000/health)

Остановить проект:
```bash
docker compose down
```

## Демо-данные и учётные записи

Стенд полностью автономен и работает на встроенных синтетических профилях:

- **Демо-OTP код для подписания договоров ПЭП:** `1234`
- **Роли:**
  - **Собственник / CEO:** создание заявки, выбор предложения, подписание договора ПЭП (OTP), получение финансирования, делегирование бухгалтеру.
  - **Главный бухгалтер:** прикрепление отчётности (ОСВ по сч. 51, декларации), ответы на дозапросы кредитного эксперта.
- **Готовые сценарии (доступны в верхней панели):**

| Пресет | Организация | Запрос | Финальный статус | Что демонстрирует |
|---|---|---|---|---|
| **Fast-track** | ИП «Кофейня на Покровке» | 500 тыс. ₽ (Овердрафт) | `APPROVED` → `FUNDED` | Сквозной путь: калькулятор → автоодобрение → выбор оффера → ввод OTP (`1234`) → `CONTRACT_SIGNED` → отдельная выдача → `FUNDED` |
| **Контр-оффер** | ООО «МеталлПром» | 20 млн ₽ (Оборотный) | `COUNTER_OFFER` | Запрос превышает лимит без залога → 3 варианта условий (меньшая сумма, зонтичное поручительство МСП, ВКЛ), расчёт переплаты и разницы |
| **Андеррайтинг** | ООО «СпецТранс» | 3 млн ₽ (ВКЛ) | `MANUAL_REVIEW` | Сезонный спад выручки → экспертный дозапрос пояснений/ОСВ → загрузка документов → повторный скоринг |
| **Отказ** | ООО «ВекторТрейд» | 10 млн ₽ (Оборотный) | `REJECTED` | Стоп-факторы (блокировка счета ФНС, просрочка 90+) → персонализированная дорожная карта оздоровления |
| **Чистый ввод** | Новая компания | Калькулятор | `DRAFT` | Расчёт Safe Cash-Flow (DTI), сохранение параметров через `PATCH /applications/{id}`, автозаполнение по ИНН |

## Пошаговый сценарий проверки за 3 минуты

### Сценарий 1: Fast-track (Сквозной путь до зачисления средств)
1. Выберите пресет **«Fast-track»** в верхней панели. Заявка находится в статусе `APPROVED`.
2. В блоке решения нажмите **«Выбрать это предложение»** на рекомендованном варианте.
3. Ознакомьтесь с индивидуальными условиями договора и нажмите **«Перейти к подписанию по СМС»**.
4. Введите демо-код **`1234`** и нажмите **«Подписать договор»**.
5. Заявка переходит в статус **`CONTRACT_SIGNED`** (договор подписан, но деньги ещё не зачислены).
6. Нажмите **«Получить финансирование»** — выполняется отдельная транзакция зачисления на расчётный счёт (`FUNDED`).

### Сценарий 2: Небинарный контр-оффер
1. Переключитесь на пресет **«Контр-оффер»**.
2. В блоке «Почему банк предложил эти условия» изучите скоринговые факторы и ограничители лимита.
3. Оцените 3 адаптивных варианта (сравнение с запрошенной суммой, ежемесячный платёж, переплата за весь срок, обеспечение).

### Сценарий 3: Андеррайтинг и дозапрос документов
1. Переключитесь на пресет **«Андеррайтинг»**.
2. В кабинете клиента отображается карточка запроса пояснений по выручке.
3. Напишите комментарий или прикрепите документ (поддерживаются файлы до 25 МБ) и отправьте ответ эксперту.
4. В правой колонке банка (АРМ Андеррайтера) скорректируйте ставку или лимит и утвердите решение.

## Ключевой REST API контракт

| Метод | Путь | Описание | Бизнес-правило / Валидация |
|---|---|---|---|
| `GET` | `/health` | Проверка здоровья сервиса | Возвращает статус `ok`, активный пресет, количество заявок |
| `GET` | `/api/presets` | Список доступных пресетов | Возвращает пресеты и активный `active_preset_id` |
| `POST` | `/api/presets/{id}/load` | Загрузка сценария | Сбрасывает состояние, инициализирует компанию и заявку |
| `GET` | `/api/applications/{id}` | Полные данные заявки | Включает скоринг, офферы, план оздоровления, аудит-лог |
| `PATCH` | `/api/applications/{id}` | Изменение параметров черновика | Доступно **только в статусе `DRAFT`**. Валидирует продукт и лимиты, инвалидирует старый скоринг, пишет `UPDATE_DRAFT` в аудит |
| `POST` | `/api/applications/{id}/transition` | Переход по FSM конвейера | Прямой вызов `SIGN_CONTRACT` **запрещён** (требует эндпоинт `/sign` с OTP) |
| `POST` | `/api/applications/{id}/sign` | Подписание договора ПЭП | Требует статус `OFFER_ACCEPTED` и OTP `1234`. Переводит в `CONTRACT_SIGNED`. Не выдаёт деньги автоматически! |
| `POST` | `/api/applications/{id}/disburse` | Выдача финансирования | Требует статус `CONTRACT_SIGNED`. Переводит в `FUNDED`. Повторные вызовы идемпотентны |
| `POST` | `/api/applications/{id}/documents` | Загрузка документов | Лимит 25 МБ. Форматы: PDF, PNG, JPG, XLSX. Безопасные имена файлов |
| `POST` | `/api/applications/{id}/delegate` | Делегирование бухгалтеру | Передаёт права на прикрепление отчётности бухгалтеру |

## Диагностика и устранение неполадок (Troubleshooting)

1. **Порт 3000 или 8000 уже занят:**
   ```bash
   # Проверить занятые порты
   lsof -i :3000
   lsof -i :8000
   # Остановить мешающие процессы или контейнеры
   docker compose down
   ```
2. **Пересборка контейнеров с нуля без кэша:**
   ```bash
   docker compose build --no-cache
   docker compose up
   ```
3. **Проверка логов бэкенда:**
   ```bash
   docker compose logs -f backend
   ```
4. **Проверка прав на загрузку файлов:**
   Директория `uploads` монтируется как том `backend-uploads` в `/app/uploads` внутри контейнера бэкенда.
