# 🅰️ АЛЬФА-БАНК: Кредитный конвейер МСБ (Smart Credit Conveyor)

Интеллектуальная система кредитования малого и микробизнеса с прозрачной логикой принятия решений, Explainable AI, поддержкой Split-Screen режима и соблюдением дизайн-системы Альфа-Банка.

---

## 🌟 Ключевые возможности

1. **Единая дизайн-система Альфа-Банка**:
   - Фирменная светлая палитра (Alfa Red `#EF3124`, светлые бенто-карточки `rounded-3xl`, чистая типографика).
   - Поддержка трех режимов отображения: **«Кабинет предпринимателя»**, **«Split-Screen»** (6+6 колонок) и **«Внутри Банка»**.

2. **5 синтетических бизнес-сценариев (Demo God-Bar)**:
   - **Fast-track** (`coffee_shop_ip`): автоодобрение без залога за 2 минуты (ИП «Кофейня на Покровке», скоринг 860).
   - **Контр-оффер** (`manufacturing_ooo`): небинарное решение и 3 гибких альтернативы финансирования (ООО «МеталлПром»).
   - **Ручной андеррайтинг** (`logistics_seasonal`): дозапрос ОСВ, human-in-the-loop разбор (ООО «СпецТранс»).
   - **Отказ + Реабилитация** (`wholesale_rejected`): стоп-факторы ФНС/БКИ и 60-дневный пошаговый план оздоровления.
   - **Чистый ввод** (`custom_input`): ручной ввод ИНН и параметров.

3. **Аналитический терминал банка (Внутри Банка)**:
   - **FSM Граф состояний заявки**: визуализация текущего шага и переходов конечного автомата.
   - **Цифровой комплаенс и обогащение**: данные ФНС (ст. 76 НК РФ, разрывы НДС), ЕГРЮЛ, БКИ и транзакционной истории.
   - **ML-Скоринг и SHAP-водопад**: прозрачная декомпозиция влияния каждого фактора на итоговый балл.
   - **АРМ Андеррайтера**: ручная корректировка ставки, лимита и срока, принятие решений и логирование.
   - **Неизменяемый аудит-лог (Audit Trail)**: история каждого перехода и действия участников.

4. **Инструменты для предпринимателя**:
   - **Safe Cash-Flow Калькулятор**: расчет долговой нагрузки (DTI) и комфортного лимита.
   - **Радар мер господдержки**: умный подбор субсидий Минэкономразвития и гарантий Корпорации МСП по коду ОКВЭД.
   - **Делегирование бухгалтеру**: отправка защищенной ссылки для прикрепления отчётности.
   - **Электронное подписание**: подтверждение условий через SMS OTP и моментальное зачисление средств.

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Recharts, Zustand, Axios.
- **Backend**: Python 3.10+, FastAPI, Pydantic v2, Uvicorn, Statemachine, HTTPX.
- **Тестирование и верификация**: Playwright (автоматизированный сквозной UI-аудит), Pytest.
- **Деплой**: Vercel (Frontend SPA + Python Serverless Functions).

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/goldymiss11/alfabank-lk.git
cd alfabank-lk
```

### 2. Запуск Backend
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.
